# Регламент работы: Claude Code ↔ Cowork Bridge

## Порядок действий

### Шаг 1: Подготовка (делаешь ДО начала диалога с Cowork)

1. Открой Chrome
2. Зайди на https://tailwindui.com
3. Залогинься в свой аккаунт
4. Оставь браузер открытым

### Шаг 2: Запуск Cowork

1. Открой новый диалог в Claude Cowork
2. При старте выбери папку: `/Users/alexeykrolmini/Downloads/Code/Claude-Cowork/`

### Шаг 3: Стартовый промпт

Напиши одну фразу:

```
Прочитай COWORK_INSTRUCTIONS.md и проверь tasks-001.md. Tailwind UI открыт и авторизован.
```

(Замени `tasks-001.md` на актуальный номер файла задач)

### Шаг 4: Cowork работает

Cowork:
- Читает инструкции
- Читает файл задач
- Подтверждает, что видит задачи
- Заходит на Tailwind UI через Chrome (уже авторизован)
- Скачивает компоненты
- Сохраняет в `results/`
- Обновляет файл задач

### Шаг 5: Завершение

Cowork сообщает: «Готово, задачи выполнены»

Ты возвращаешься в Claude Code — результаты в папке `results/`

---

## Важно

- **Логин в Tailwind — ДО диалога с Cowork**, не после
- **Никаких дополнительных сигналов не нужно** — фраза «Tailwind UI открыт и авторизован» = разрешение идти на сайт
- **Браузер должен быть открыт** — не закрывай Chrome во время работы

---

## Если что-то пошло не так

| Проблема | Решение |
|----------|---------|
| Cowork не видит файл задач | Проверь, что выбрал правильную папку при старте |
| Tailwind показывает «Sign in» | Залогинься заново, скажи Cowork повторить |
| Компонент не найден | Cowork переместит задачу в Clarification Needed |
| Браузер завис | Перезагрузи Chrome, залогинься, скажи Cowork продолжить |

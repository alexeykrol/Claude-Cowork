# Claude-Cowork Bridge

**Универсальный мост между Claude Code (CLI) и Claude Cowork (Desktop/Web) для запроса UI компонентов из Tailwind UI.**

---

## Что это?

Это локальная рабочая папка для обмена задачами между:
- **Claude Code** (терминал, без доступа к браузеру)
- **Claude Cowork** (десктоп/веб, с доступом к браузеру)

**Используется для:**
- Скачивания компонентов из Tailwind UI (требует авторизации)
- Других задач, где нужен браузер

---

## Структура

```
Claude-Cowork/
├── README.md                      ← Этот файл
├── CLAUDE_CODE_BRIDGE.md          ← Архитектура моста
├── COWORK_INSTRUCTIONS.md         ← Инструкции для Cowork
├── QUICK_REFERENCE.md             ← Быстрая справка
├── START_PROMPT.txt               ← Стартовая команда для Cowork
├── WORKFLOW_РЕГЛАМЕНТ.md          ← Регламент работы
│
├── scripts/                       ← Автоматизация
│   ├── watch-cowork-results.sh    ← Мониторинг результатов
│   └── create-task-file.cjs       ← Генератор task files
│
├── tasks-NNN-TIMESTAMP.md         ← Файлы задач
├── tasks-template.md              ← Шаблон
│
└── results/                       ← Скачанные компоненты
    └── task-NNN-XXX-name.tsx
```

## Как это работает

### 1. Claude Code создаёт задачи

В любом проекте (ai-test02, another-app, etc.) вызывается команда:

```
/request-components
```

Это:
- Генерирует `tasks-NNN-TIMESTAMP.md` **в этой папке**
- Запускает мониторинг результатов (фоновый процесс)
- Показывает инструкции пользователю

### 2. Пользователь запускает Cowork

1. Открывает Claude.ai (Desktop/Web)
2. Создаёт новый диалог
3. Выбирает **эту папку** (`Claude-Cowork/`)
4. Говорит: "Прочитай COWORK_INSTRUCTIONS.md и найди актуальный файл задач"

### 3. Cowork выполняет

- Читает `tasks-NNN-TIMESTAMP.md`
- Скачивает компоненты через браузер
- Сохраняет в `results/` с правильным именованием
- Обновляет статус задач

### 4. Claude Code продолжает

- Мониторинг обнаруживает новые файлы
- Автоматически уведомляет
- Интегрирует компоненты в проект

## Универсальность

Эта папка **НЕ привязана к конкретному проекту**.

Она работает с любым проектом:

```
~/Downloads/Code/
├── Claude-Cowork/          ← Один мост для всех
│
├── ai-test02/              ← Проект 1 (React)
│   └── .claude/commands/request-components.md
│
├── another-react-app/      ← Проект 2 (React)
│   └── .claude/commands/request-components.md
│
└── some-next-app/          ← Проект 3 (Next.js)
    └── .claude/commands/request-components.md
```

Каждый проект имеет команду `/request-components`, которая:
- Использует **эти же** скрипты
- Создаёт задачи **в этой** папке
- Получает результаты **отсюда**

## Важно

### ⚠️ НЕ коммитить в Git

Эта папка - **локальная инфраструктура**.

- Не добавляйте в Git проектов
- Не пушите на GitHub
- Она должна быть только на вашей локальной машине

### 🔒 Приватность

- Файлы задач содержат URLs и описания
- Результаты содержат код из Tailwind UI (платная подписка)
- Всё остаётся локально

### 🔄 Обновления

Когда обновляются скрипты или инструкции:
- Обновите файлы **здесь**
- Все проекты автоматически получат обновления
- Не нужно синхронизировать между проектами

## Быстрый старт

### Для нового проекта

1. Убедитесь, что проект имеет команду `/request-components`
2. Вызовите команду из проекта
3. Следуйте инструкциям

### Ручной запуск

```bash
# Посмотреть задачи
ls -lh tasks-*.md

# Запустить мониторинг
bash scripts/watch-cowork-results.sh 002

# Посмотреть результаты
ls -lh results/
```

## Troubleshooting

### "Файлы задач не найдены"

**Решение:** Убедитесь, что файл в этой папке, имя `tasks-NNN-TIMESTAMP.md`

### Мониторинг не реагирует

**Решение:** Проверьте формат имени результата: `task-NNN-XXX-*.{tsx,html,vue}`

### Cowork не может скачать

**Решение:** Проверьте авторизацию в Tailwind UI, проверьте URL

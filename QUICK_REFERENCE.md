# Quick Reference: Cowork Bridge Workflow

Быстрая справка по использованию Claude Code ↔ Cowork Bridge для запроса UI компонентов.

---

## Для Claude Code (терминал)

### Команда: `/request-components`

**Когда использовать:**
- Нужен компонент из Tailwind UI
- Автоматически определяет потребность во время работы

**Что делает:**
1. Собирает требования к компонентам
2. Генерирует файл задач `tasks-NNN-TIMESTAMP.md`
3. Запускает фоновый мониторинг результатов
4. Показывает инструкции для пользователя

**Пример использования:**
```
User: /request-components
Claude: Какие компоненты нужны?
User: Pricing section с тремя тарифами
Claude: [Создает task file, запускает мониторинг]
```

## Для пользователя

### Шаг 1: Claude Code создает задачи

Вы увидите сообщение:
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🎨 Запрос компонентов создан
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 Файл задач: tasks-002-20260118T153000.md
📁 Путь: Claude-Cowork/tasks-002-20260118T153000.md

Создано задач: 1

🔄 Фоновый мониторинг запущен
```

### Шаг 2: Запустите Cowork

1. Откройте **Claude.ai** (Desktop или Web)
2. Создайте новый диалог
3. Выберите папку `Claude-Cowork/` для работы
4. Скажите:

```
Прочитай COWORK_INSTRUCTIONS.md и найди актуальный файл задач
```

### Шаг 3: Авторизуйтесь в Tailwind UI

1. Откройте Chrome
2. Перейдите на https://tailwindui.com
3. Залогиньтесь (если не залогинены)
4. Подтвердите Cowork, что браузер готов

### Шаг 4: Cowork выполняет задачи

Cowork автоматически:
- Находит актуальный файл задач
- Читает задачи из секции `Pending`
- Скачивает компоненты
- Сохраняет в `results/` с правильным именованием
- Обновляет статус задач

### Шаг 5: Claude Code продолжает автоматически

Когда файлы появляются в `results/`, мониторинг обнаруживает их и Claude Code:
- Автоматически уведомляет вас
- Предлагает интегрировать компоненты
- Продолжает работу над задачей

## Структура файлов

### Task File (`tasks-NNN-TIMESTAMP.md`)

Пример задачи:
```markdown
### task-002-001
- **id**: task-002-001
- **created**: 2026-01-18T15:30:00
- **priority**: high
- **component**: Pricing Section
- **source_url**: https://tailwindui.com/components/marketing/sections/pricing
- **specific_variant**: Three tiers with toggle
- **framework**: React
- **output_file**: results/task-002-001-pricing-section.tsx
- **notes**: Нужен вариант с тёмным фоном
- **status**: pending
```

### Results (`results/`)

Формат имени: `task-[NNN]-[XXX]-[component-name].[ext]`

Примеры:
- `task-001-001-radio-group-cards.tsx`
- `task-002-003-pricing-section.tsx`
- `task-001-002-hero-section.html`

**Почему такое именование:**
- Префикс `task-001-001` — для автоматической идентификации
- Мониторинг отслеживает файлы по префиксу
- Легко понять, какой файл для какой задачи

---

## Статусы задач

| Статус | Значение |
|--------|----------|
| `pending` | Ожидает выполнения |
| `in_progress` | Cowork сейчас выполняет |
| `done` | Выполнено успешно |
| `failed` | Ошибка (см. result_notes) |
| `clarification_needed` | Нужно уточнение |

## Troubleshooting

### Cowork не находит файл задач

**Проблема:** "Файлы задач не найдены"

**Решение:**
- Проверьте, что файл в папке `Claude-Cowork/`
- Имя должно быть `tasks-NNN-TIMESTAMP.md`
- Используйте Glob: `tasks-*.md`

### Мониторинг не видит результаты

**Проблема:** Файлы есть, но мониторинг не реагирует

**Решение:**
- Проверьте формат имени: должен быть `task-NNN-XXX-*.{tsx,html,vue}`
- Файл должен быть в `Claude-Cowork/results/`
- Убедитесь, что префикс совпадает с номером task file

### Cowork не может скачать компонент

**Проблема:** Статус `failed` или `clarification_needed`

**Решение:**
- Проверьте `result_notes` в задаче
- Убедитесь, что авторизованы в Tailwind UI
- Проверьте, что URL корректный
- Уточните `specific_variant`

## Полезные команды

```bash
# Посмотреть task files
ls -lh ~/Downloads/Code/Claude-Cowork/tasks-*.md

# Посмотреть результаты
ls -lh ~/Downloads/Code/Claude-Cowork/results/

# Посмотреть результаты конкретной задачи
ls -lh ~/Downloads/Code/Claude-Cowork/results/task-002-*

# Вручную запустить мониторинг
bash ~/Downloads/Code/Claude-Cowork/scripts/watch-cowork-results.sh 002
```

## Схема workflow

```
┌─────────────────────┐
│  Claude Code (CLI)  │
│                     │
│ /request-components │ ─── 1. Создаёт task file
└─────────────────────┘
          │
          │ 2. Запускает мониторинг (фон)
          ▼
    ┌──────────┐
    │ Ожидание │
    └──────────┘
          │
          │ (пользователь переключается на Cowork)
          │
┌─────────────────────┐
│ Claude Cowork (Web) │
│                     │
│ 3. Читает tasks.md  │
│ 4. Скачивает код    │
│ 5. Сохраняет в      │
│    results/         │
└─────────────────────┘
          │
          │ 6. Мониторинг обнаруживает файлы
          ▼
┌─────────────────────┐
│  Claude Code (CLI)  │
│                     │
│ 7. Уведомляет       │
│ 8. Интегрирует      │
│ 9. Продолжает       │
└─────────────────────┘
```

## Timing

- **Генерация task file:** < 1 секунда
- **Cowork выполнение:** 1-3 минуты на компонент
- **Мониторинг проверка:** каждые 5 секунд
- **Максимальное ожидание:** 10 минут (таймаут)

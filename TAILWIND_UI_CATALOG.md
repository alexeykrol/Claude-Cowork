# Tailwind UI Component Catalog

**Справочник доступных компонентов из Tailwind UI для быстрого выбора темплейтов.**

> **Важно:** Всегда консультируйтесь с этим каталогом ПЕРЕД написанием нового UI компонента!

**Официальный сайт:** https://tailwindui.com/components

---

## 📋 Как пользоваться

1. **Определите тип компонента** (форма, навигация, карточка и т.д.)
2. **Найдите категорию** в этом каталоге
3. **Выберите варианты** (обычно 3-5 вариантов на категорию)
4. **Спросите пользователя**, какой вариант использовать
5. **Используйте `/request-components`** для получения кода

## 💡 Tips

1. **Начинайте с категории** - не с конкретного компонента
2. **Смотрите варианты** - обычно 5-10 вариантов в категории
3. **Спрашивайте пользователя** - даже если кажется очевидным
4. **Комбинируйте** - можно взять несколько компонентов
5. **Адаптируйте** - темплейт = стартовая точка, не догма
